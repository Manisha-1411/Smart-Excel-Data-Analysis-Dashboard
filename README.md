# 📊 Smart Data Analysis Dashboard

An interactive, enterprise-grade web application built in Python using Streamlit to dynamically parse, clean, and visualize complex financial datasets (CSV/Excel).

## 🚀 Key Features
- **Dynamic Time Filtering:** Instantly switches data views across Daily, Weekly, and Monthly aggregates using Pandas groupby optimization.
- **Custom Aesthetic & Layout:** Professional blue abstract UI with a dual-column chart view (Bar & Pie Charts) using the Plotly Dark engine.
- **Interactive Chart Controls:** Users can isolate individual charts or view them concurrently in full-width displays.
- **Robust Fallbacks:** Auto-detects columns and provides custom layout dropdowns to prevent unexpected crashes with raw formats.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **IDE:** Antigravity IDE
- **Frontend UI:** Streamlit & Custom CSS
- **Data Manipulation:** Pandas
- **Interactive Graphs:** Plotly Express

## 💻 How to Run Locally
1. Clone this repository.
2. Install dependencies: `pip install streamlit pandas plotly`
3. Spin up the application: `streamlit run app.py`
